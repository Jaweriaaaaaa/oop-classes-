# C++ Practice Questions

## 📖 About This Repository

This repository contains my C++ programming practice questions completed during my Bachelor's in Software Engineering coursework. The purpose of this repository is to document my learning journey, strengthen my problem-solving skills, and keep all of my practice work organised in one place.

The questions range from beginner to intermediate level and cover the fundamental concepts of C++ programming that I have learned throughout my classes. Each solution was written to improve my understanding of programming logic, syntax, and algorithmic thinking.

## 📚 Topics Covered

This repository includes practice questions related to:

* Variables, Data Types, and Operators
* Input and Output
* Conditional Statements (`if`, `if-else`, `switch`)
* Loops (`for`, `while`, `do-while`)
* Functions
* Arrays (1D and 2D)
* Strings
* Pattern Printing
* Structures (`struct`)
* Unions (`union`)
* Enumerations (`enum`)
* Pointers
* Dynamic Memory Allocation
* File Handling
* Basic Object-Oriented Programming (Classes and Objects)
* Constructors and Destructors
* Copy Constructors
* Problem-Solving and Logic Building
